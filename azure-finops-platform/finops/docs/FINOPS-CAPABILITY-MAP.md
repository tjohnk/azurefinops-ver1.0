# FinOps capability coverage

Based on Microsoft's FinOps Framework domains.

## Understand usage and cost
- Data ingestion: ADLS + ADX collectors
- Allocation: FinOpsAllocationFact + tagging
- Reporting/analytics: web portal + ADX
- Anomaly management: CostAnomalyFact + runbook

## Quantify business value
- Planning/estimating: budget model
- Forecasting: CostForecastFact
- Budgeting: CostBudgetFact
- Benchmarking: service/application/environment comparisons
- Unit economics: portal model ready for business KPI inputs

## Optimize usage and cost
- Architecting: optimization recommendations
- Workload optimization: utilization/right-sizing
- Rate optimization: commitment fact
- Licensing/SaaS: recommendation model
- Sustainability: extensible sustainability dataset

## Manage the FinOps practice
- Education/enablement: documentation/runbooks
- Practice operations: monthly/weekly cadence
- Workload onboarding: onboarding checklist
- Policy/governance: Azure policy/tag standards
- Invoicing/chargeback: allocation model
- FinOps assessment: maturity fact
- Tools/services: tool inventory
- Intersecting frameworks: governance/security/Well-Architected integration

Important: the platform implements the technical capabilities. Organizational decisions, ownership, policy approval, budgeting authority and finance processes still belong to your organization.
