# Allocation runbook

Primary dimensions:
Environment, Subscription, Resource Group, Application, Business Unit, Cost Center, Owner, Project and Service.

Rules:
- Directly attributable costs go to the owning application/team.
- Shared platform costs use an explicit allocation method.
- Missing allocation metadata goes to an exception queue.
- Allocation rules are versioned and reviewed periodically.
- Never silently assign unowned cost to a random team.
