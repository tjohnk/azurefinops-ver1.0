# Cost anomaly runbook

1. Detect anomaly using cost/usage baseline.
2. Classify severity.
3. Identify resource, service, application, owner and environment.
4. Compare recent deployment/configuration/activity changes.
5. Determine expected versus unexpected growth.
6. Create an ADO work item for actionable anomalies.
7. Assign owner and due date.
8. Record root cause.
9. Remediate or document accepted variance.
10. Validate cost returns to expected range.
11. Record realized savings if applicable.
12. Close anomaly and retain evidence.

Do not automatically delete resources solely because an anomaly is detected.
