# Optimization workflow

New -> Triaged -> Accepted/Rejected -> InProgress -> Implemented -> Validated -> Closed

Recommendation sources:
- Azure Advisor
- Utilization analysis
- Unused resource analysis
- Rightsizing
- Storage lifecycle opportunities
- Commitment utilization
- Licensing/Hybrid Benefit
- Architecture review
- Sustainability signals

Every recommendation should capture:
resource, owner, environment, current cost, expected savings, recommendation, priority, due date, implementation status and validated savings.
