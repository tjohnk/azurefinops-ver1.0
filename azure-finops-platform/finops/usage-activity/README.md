# Usage & Activity Module

Complete portal module for Sandbox, Dev, Staging and Production.

Reports include overview, last activity, active/inactive, service adoption, never-used,
90+ day inactivity, trends, resource changes, identity activity, failures, start/stop,
deployments, VM utilization, App Service, Storage, SQL, health, heatmap, environment x
service and usage-to-cost correlation.

Recommended sources: Azure Resource Graph, Azure Monitor, Azure Activity Log, Azure DevOps,
Resource Health and Service Health. Collect into ADX and expose through authenticated APIs.
Do not let the browser query Azure directly.
