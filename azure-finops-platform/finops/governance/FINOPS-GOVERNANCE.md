# FinOps governance

## Required controls

1. Required tagging policy.
2. Owner validation.
3. Application and cost-center mapping.
4. Budget ownership.
5. Budget threshold alerts.
6. Cost anomaly alerts.
7. SKU/location restrictions where justified.
8. Optimization recommendation tracking.
9. Commitment utilization monitoring.
10. Exception management.
11. Monthly FinOps review.
12. Quarterly maturity assessment.

## Recommended rollout

Phase 1: Audit and visibility.
Phase 2: Alerts and accountability.
Phase 3: Automated workflows.
Phase 4: Selective enforcement.

Start with audit rules before deny policies. Governance should not block legitimate engineering work without an approved exception path.
