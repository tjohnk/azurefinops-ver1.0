# Cost Analysis Module

This module adds a complete Cost Analysis tab to the Azure Estate Intelligence portal.

Reports:
1. Overview
2. Cost Trend
3. Cost by Environment
4. Cost by Service
5. Cost by Resource
6. Cost by Resource Group
7. Cost by Application
8. Cost by Business Unit
9. Cost by Owner
10. Unallocated Cost
11. Cost Anomalies
12. Budget vs Actual
13. Forecast
14. Cost by SKU
15. Cost by Region
16. Compute
17. Storage
18. Networking
19. Monitoring
20. Cost increases
21. Environment x Service

All views support Sandbox, Dev, Staging and Production where applicable.
